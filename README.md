# Něco jako Wordle

Jednoduchá webová aplikace inspirovaná populární hrou **Wordle**, vytvořená jako školní projekt v PHP.

## About
* **Wordle** – hádání 5místného slova s vyhodnocením písmen.
* **Statistiky** – počítání pokusů, nejčastějších slov a historie her.
* **Mini Wiki** – dynamické načítání nápovědy a dalších stránek ze složky.
* **Hodnocení** – formulář pro ukládání hodnocení od hráčů.

## Požadavky
- PHP
- Apache server
- XAMPP nebo jiný lokální webový server

## Spuštění
1. Přesuňte projekt do složky `htdocs`.
2. Spusťte Apache v XAMPP.
3. Otevřete projekt v prohlížeči.
